# Scanerate

Scan and generate QR codes & barcodes — one Expo app for web, Android and iOS.

> 🚧 Work in progress

## Planned features

- Scan QR codes and barcodes with the camera (web and mobile)
- Preview links before opening, with a warning for unsafe URLs
- Generate QR codes (link, text, Wi-Fi, contact) and barcodes
- Export as PNG / SVG and keep a scan history
- Thai / English and dark mode

## Tech stack

React Native · Expo (Expo Router) · TypeScript · react-native-web

## Run locally

```bash
npm install
npm run web      # browser
npm run android  # Android
npm run ios      # iOS
```
